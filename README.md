# Jason Dennis - Portfolio & Web Applications

Welcome to my collection of web applications and projects hosted on GitHub Pages! This repository showcases various interactive tools I've developed using different technologies.

## 🚀 Live Applications

Visit the [**Portfolio Landing Page**](https://jdennisuf.github.io) to explore all applications, or access them directly:

### 🎵 [Jingler - The Jingle Maker](https://jdennisuf.github.io/jingler/)
A modern web-based automatic jingle generator that creates random, single-measure musical phrases with professional audio synthesis and musical notation.

**Features:**
- 15 musical scales (major/minor keys)
- 6 synthesizer types with multiple waveforms
- Real-time musical staff notation
- Customizable tempo, note count, and duration
- Jingle library with editing and PNG export

**Tech Stack:** Tone.js, VexFlow, Vanilla JavaScript

### 🏥 [ICD Diagnostics](https://jdennisuf.github.io/icdiags/)
A comprehensive search tool for ICD-10 diagnostic codes with voice input capabilities.

**Features:**
- Fast diagnostic code search
- Voice recognition input
- Responsive Bootstrap interface
- Client-side SQLite database

**Tech Stack:** Blazor WebAssembly, C#, Entity Framework, JavaScript

### 📚 [UbiFlash - Flashcards App](https://jdennisuf.github.io/flashcards/)
An interactive flashcard learning application with multiple subject categories.

**Features:**
- Multiple subject categories (Spanish, Science, Geography, etc.)
- Progressive learning system
- Mobile-responsive design
- Offline capability

**Tech Stack:** Flutter, Dart

## 🛠 Development

### Local Development
```bash
# Clone the repository
git clone https://github.com/jdennisuf/jdennisuf.github.io.git
cd jdennisuf.github.io

# Start local development server
node server.js
# Or use any static file server
python3 -m http.server 8000
```

### Project Structure
```
├── index.html          # Portfolio landing page
├── server.js           # Local development server

```
